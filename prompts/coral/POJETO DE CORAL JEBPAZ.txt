POJETO DE CORAL JEBPAZ FEITO COM ANGULAR

CONTEXTO
Interface única (SPA simples). Não há múltiplas páginas; tudo acontece dentro de uma única rota com estados de tela controlados internamente.

Estrutura Geral
A aplicação será organizada por features, mesmo com uma única rota. Isso evita acoplamento e mantém crescimento controlado.

core/ → serviços globais
features/ → exportar pdf
shared/ → componentes reutilizáveis (botões, inputs, cards)

Mesmo sem múltiplas rotas, cada feature é isolada.

COPONETES
- COMPONENTES BURROS - recebe dados via input signal, emiti dados via output signal, não contém regra de negocio;
- COMPONENTE INTELIGENTE - controla estados com signal, chama services, dicide o que renderizar;
- nenhum componente burro acessa service;
- USO DE SIGNALS;
- DEVE TER EM ESSÊNCIA A ESTRUTURA DE UI E VALIDAÇÃO;

ROTAS
- SOMENTE ROTA "/";

ESTILO e UI
- COR PRINCIPAL DA UI "#16436C";
- SEGUIR UM PADRÃO DE ESTILO AO MATERIAL DESING;
- Tipografia e espaçamento consistentes definidos no tema global;
- O PADRÃO DO PROJETO É SCSS;
- DEVE SER RESPONSIVO E PENSADO PRIMEIRAMENTE PARA SMARTPHONE;

SERVICE
- OS DADOS DEVEM SER PROCESSADOS PRICIPALMENTE EM SERVICES;
- USADA PRO FEATURES;

REGRAS
- USAR SEMPRE STANDALONE;
- Sem uso de NgModules tradicionais;
- Estrutura previsível de pastas;
- Nenhuma lógica de negócio em HTML;
- Os métodos sempre deve dizer se são publicos ou privados;
- Os métodos sempre deve dizer o tipo de retorno;
- Nunca deve utilizar tipos harded coded, sempre usar interfaces ou types;
- Toda ação destrutiva deve ter uma dupla confirmação;
